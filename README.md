# Abhishek Bari — GitHub Pages Portfolio

This is a static HTML/CSS/JavaScript version prepared for free hosting with GitHub Pages. It does not require PHP or a Laravel server.

4. Check every link and preview on mobile.

## Publish free with GitHub Pages

1. Sign in to https://github.com/ or create an account.
2. Create a **public** repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
3. Upload the contents of this folder to the repository root. Upload `index.html`, the `assets` folder, and `PORTFOLIO-CONTENT.md` — not the parent folder itself.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes, then visit `https://YOUR-USERNAME.github.io/`.
