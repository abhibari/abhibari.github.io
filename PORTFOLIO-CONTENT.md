# Personalize your portfolio

Replace the placeholders in `resources/views/portfolio.blade.php`:

- `[YOUR NAME]` — your professional name
- `you@example.com` — your contact email
- GitHub and LinkedIn URLs
- Work experience, dates, responsibilities, and impact
- Project names, summaries, GitHub links, and live demos
- Skills you can confidently discuss in an interview

## Recommended case-study structure
For each project, explain:
1. The problem and intended user
2. Your role and what you personally implemented
3. Architecture and key technical decisions
4. API, database, security, and testing considerations
5. Results (only measured/verified outcomes)
6. GitHub repository or live demo

## Strong Laravel project ideas
Pick projects you have actually built or are willing to build:
- API-first task/workflow platform with Sanctum authentication, policies, validation, queues, and feature tests
- Expense tracker with import, categorization, reporting, and dashboard
- Inventory/order system with transactions, role-based access, audit history, and automated tests

Avoid listing tools or skills you cannot explain clearly.
